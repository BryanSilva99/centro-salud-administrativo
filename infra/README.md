# Infraestructura

`local/compose.yml` prepara una base PostgreSQL opcional de desarrollo; no se ejecutó. No hay despliegue de la aplicación ni de SigNoz implementado.

- `deployment/`: futura configuración de ejecución y secretos por entorno.
- `observability/`: futura configuración de SigNoz y recepción de telemetría.

La selección del proveedor y la implementación requieren una indicación posterior. No se incorporan credenciales ni datos locales al repositorio.
