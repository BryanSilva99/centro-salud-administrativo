# Gestión administrativa

Pantallas y componentes de esta área (RF-04 a RF-11).

- `components/RegistrarPacienteForm.tsx`, `components/BuscarPacientesPanel.tsx`, `components/EditarPacienteForm.tsx` y `api/pacientes.ts`: registro, búsqueda y edición de pacientes (RF-04, RF-05). Ver [docs/PACIENTES.md](../../../../docs/PACIENTES.md).
- `components/ServiciosPanel.tsx`, `components/ServicioForm.tsx` y `api/servicios.ts`: servicios y modalidades económicas (RF-08). Ver [docs/SERVICIOS.md](../../../../docs/SERVICIOS.md).
- `components/ConsultoriosPanel.tsx`, `components/ConsultorioForm.tsx` y `api/consultorios.ts`: consultorios y servicios compatibles (RF-09). Ver [docs/CONSULTORIOS.md](../../../../docs/CONSULTORIOS.md).
- `components/ProfesionalesPanel.tsx`, `components/ProfesionalForm.tsx` y `api/profesionales.ts`: profesionales y servicios habilitados (RF-07). Ver [docs/PROFESIONALES.md](../../../../docs/PROFESIONALES.md).
- `components/DisponibilidadPanel.tsx`, `components/TurnoForm.tsx` y `api/disponibilidad.ts`: turnos de profesionales y consultorios (RF-10). Ver [docs/DISPONIBILIDAD.md](../../../../docs/DISPONIBILIDAD.md).
